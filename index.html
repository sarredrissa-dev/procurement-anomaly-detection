IntegriScan — Government Procurement Anomaly Detection System

"Follow the money. Flag the risk." An ML-powered analytics platform designed to ingest public spending data, store it in an optimized relational database schema, run detection algorithms, and serve an interactive risk dashboard to government analysts.

Core Architecture & Modules

  • Database Layer: Configured 5 relational tables, 3 dedicated analytical views, and 26 optimization indexes.
  • ETL Pipeline: Streamlined ingestion pipeline handling FY2023 Department of Defense contract datasets (USASpending.gov).
  • Machine Learning: Built anomaly workflows utilizing Isolation Forest (-0.699 average score) and Z-Score validation features.
  • Analytics Interface: Deployed a secure Streamlit web dashboard backed by multi-level Role-Based Access Controls (RBAC).
